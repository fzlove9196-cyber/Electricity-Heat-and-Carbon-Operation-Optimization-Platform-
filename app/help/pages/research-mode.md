# 研究模式

> **目的**：把「一句中文问题」组织成研究闭环：问题卡 → 澄清 → 计划 → 执行·诊断·修订 → 证据化结论 → 报告。
> **前置条件**：仿真工作台；勾选「🔬 研究模式」后发送问题。
> **界面入口**：② 仿真优化 → 🧭 仿真工作台 → ↳ 🔬 研究模式。状态：【已实现】（Mock 下由确定性规则完成）。

[▶ 打开此功能：研究模式](/?view=chat&step=research)

## 操作步骤

1. 勾选「🔬 研究模式」，输入问题，例如「中卫冬季想用余热供暖，看值不值」。
2. **问题卡**：研究问题、决策变量、约束、指标、情景、假设。
3. **澄清**：系统给出选项与默认值。可「采纳选中项」「用默认值继续」或「提交回答」；参数来源可追溯到对话消息。
4. **计划**：基线 / 主方案 / 敏感性 / 方案比较 / 压力测试 / 交流校核。可「✏️ 在右侧编辑计划」后「💾 保存计划修改」，再「✅ 批准计划并执行」。
5. **执行·诊断·修订**：检查求解状态、PUE、平衡残差、同时购售 / 充放、热裕度、DR 缺额、末端温度、紧约束与影子价格；不可行时逐项松弛定位。修订最多 3 次，需你在检查点确认（「✅ 批准并执行」）。
6. **证据化结论**：置信度、证据链 R#、依赖假设 A#。
7. 追问「💡 为什么？」「🔁 如果…会怎样？」，或「📄 生成报告」（study_report.md / html）。

## 注意

- 所有数字来自实际运行结果；「如果…」追问会重算主方案与同工况基线。
- 研究模式的「修订」是研究诊断重跑，**不等同于**三级运行中的「日内滚动」。
- 方法卡 / 经验卡需要你勾选采纳后才写入技能卡。
