# 典型流程与示例提示词

> **目的**：按常见业务目标给出可直接照做的流程和对话提示词。
> **前置条件**：无。示例默认使用**合成数据或公开资料等值场景**，结论仅用于方法演示。
> **界面入口**：仿真工作台输入框；项目与场景。

[▶ 打开此功能：仿真工作台](/?view=chat)

## 流程 A：项目化日调度闭环（中卫等效场景）

1. 项目与场景：创建项目 → 模板「风光储直供参考·中卫」→ 时间轴 `中卫 / 2024 / Asia/Shanghai / 2024-07-01T00:00:00+08:00 / 60 / 24` → 从模板新建。
2. 绑定「公开气象·中卫·2024-07-01」到场景公共信号（若草稿为示例地点，用替换 + 对齐时间轴）。
3. 校验与展开 → 发布 v1。
4. 版本化任务：`cost` 或 `weighted_carbon` → 创建冻结任务 → 运行。
5. 查看当时模型与结果 → 结果与分析 → 运行日志与交流校核 → 三级运行（日前基线、日内滚动）。
6. 必要时按原快照重跑。

## 流程 B：签出编辑 → 写回 → 发布新版本

签出草稿 → 拓扑编辑器修改（如 PUE 1.35 → 1.40）→ 写回场景草稿 → 发布 v2 → 新任务。v1 任务结果保持不变，可对比。

## 流程 C：日前 → 三级运行 → 交易沙盘 → 复盘

工作台求解日前最优 → 三级运行（基线 / 滚动 / 可行域 / 实时）→ 运营工作台闭环 → 结果复盘 → 沉淀技能卡。三级运行与交易沙盘模型并不完全相同，结论不能机械互换。

## 流程 D：年度 CFE

项目页「年度CFE公开原输入」→ 新建独立场景 → 设置匹配规则 → 写入编辑器 → 保存 / 校验 / 发布 → 任务（cost、AC 关闭）→ 年度结果 → 正式 ZIP。
