## 主要 KPI

| 类别 | 指标 |
|---|---|
| 经济 | 成本（不含碳成本）、碳成本；福利模式另列接纳价值与服务费 |
| 碳 | 排放（位置 / 发电口径）、数据中心碳强度、绿电率；生命周期分账（若启用，单独列） |
| 热 | 动态 PUE、入口温度范围与裕度、冷却 / 蓄冷 / 余热；终端实际用热、管段到达、管损、节点储热损失分列 |
| 任务 | 截止满足率、未完成量、迁移量、链路利用率 |
| DR | 要求与实际响应 |

## 收益归因

按「基线 → 仅负荷时移 → +跨中心迁移 → +储能 → +虚拟储冷 → +余热 → +DR」顺序求解反事实 LP 分解节省。分解次序会影响交互效应的归属。

交流校核（pandapower）只针对峰值或指定时刻，**不是全时段交流 OPF**；关注收敛、电压范围、最大负载率、网损、越限。

## 导出

| 导出 | 入口 | 内容 |
|---|---|---|
| 可复现运行包 | 结果后「导出可复现报告」或 `/api/sessions/{sid}/export.zip` | `scenario.json`、`params.json`、`formulation.json`、`solver_config.json`、`input_snapshot.json`、`runlog.json`、`results.json`、`dispatch_*.csv`、任务 / 迁移 / 网络 / 热 / 整数事件表、`reproduce.py`、`README.md` |
| 独立模式正式 ZIP | 任务页结果区，`/api/foundation/tasks/{id}/export.zip` | 见各模式篇章 |
| 任务 JSON | 任务页「下载任务/输入/结果JSON」 | 冻结任务记录 |

`reproduce.py` 可脱离服务用同一引擎重算并对比。

## 结果什么时候「过期」

任一会话模型改变（参数表、拓扑、配置构建器、对话修改）都会使旧 KPI、对比、拓扑结果失效，页面提示「尚无当前结果」或「旧结果已过期」。历史任务的结果与当前会话无关，不会失效。
