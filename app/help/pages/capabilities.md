# 产品能做什么、不能做什么

> **目的**：在开始使用前建立正确预期，避免把演示结果当作工程或交易结论。
> **前置条件**：无。
> **界面入口**：本页为说明性内容；完整限制清单见 [已知限制与诚实声明](/help/limitations)。

## 不能做什么

- **不是真实交易终端**：交易页的「真实提交」恒返回 HTTP 403「真实外部下单不可执行」，规则包为【假设·非官方】示范规则。
- **DR 基线不是结算级**：公开基准留出验证未达到正式结算标准，只能用于示范估算。
- **不是实时 EMS / SCADA**：三级运行是离线仿真，不下发设备指令。
- **不会从 PDF 自动可靠生成拓扑**：项目资料只登记引用与待确认项，不解析接线图；需要用模板、配置构建器、拓扑编辑器或结构化 JSON 建模。
- **示例数据不是现场数据**：默认值、示例资源、案例预设均为合成或公开资料等值参考。
- **15 分钟不会被暗中按 1 小时计算**：不支持的路径会直接报错。
- **不宣称论文全部复现**：已有部分子模型的独立对照，八篇论文整篇复现仍未完成。
- **无用户鉴权**：仅限可信本地网络使用，不应暴露到公网。

## 设计原则（理解报错的钥匙）

1. **默认不变、显式启用**：新口径都要明确选择，默认结果与旧版一致。
2. **不静默转换**：时间轴、时区、步长、长度、单位、币种不一致时拒绝，而不是重采样、截断或补值。
3. **版本只追加**：发布版本、模板、资源版本、已完成任务都不能覆盖或删除。
4. **失败如实保留**：不可行、超时、未收敛记为 failed，不回退旧计划，不伪造成功结果。
5. **口径分账**：运行碳与生命周期碳、预测与实际、到达热与终端取热分列显示。
