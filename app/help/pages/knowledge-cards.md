# 知识库与技能卡

> **目的**：上传资料供对话自动检索引用；把可复用的任务步骤沉淀为技能卡。
> **前置条件**：无。
> **界面入口**：⑥ 知识 · 工具 · 设置 → 📚 知识库、🧠 技能卡。状态：【已实现】。

[▶ 打开此功能：知识库](/?view=kb)

## 知识库

![知识库](/help/img/s1106-kb.jpg)
*截图：2026-11-06（Mock），只读浏览；左侧导航为旧版。*

1. 拖拽或点击上传：PDF / DOCX / MD / TXT / CSV / .py / .mo / .m。也可直接拖到对话框。
2. 在检索框测试检索（例如「碳感知调度 碳强度」）→ **检索**。
3. 切换嵌入模型后点 **重建向量索引**。
4. 对话时每轮自动检索，回答标注「[来源: 文件#块]」。

检索方式：jieba BM25 与本地稠密向量各取 top20 → RRF 融合 → 重排。上传的 PDF 只作为检索资料，**不会自动生成拓扑**。

> 可以把本手册的 Markdown 文件（位于服务目录 `app/help/pages/`）上传到知识库，让对话也能引用；系统不会自动写入。

## 技能卡

![技能卡](/help/img/s1106-cards.jpg)
*截图：2026-11-06（Mock）；左侧导航为旧版。*

- 在对话中说「记住：……步骤：……参数：……校验：……」，智能体自动生成技能卡；类似任务会自动检索复用。
- 也可在技能卡页「＋ 新建」手工编辑。
- 研究模式的方法卡 / 经验卡在你勾选采纳后写入。
