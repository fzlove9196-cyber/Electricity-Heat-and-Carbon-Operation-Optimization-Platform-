# 储能与 UPS 参数

> **目的**：配置站用储能或可调度 UPS 的容量、功率、效率与 SOC。
> **前置条件**：无。
> **界面入口**：② 输入参数「蓄能配置」组；拓扑编辑器添加 / 点选储能；资源库设备模型（`storage`）；JSON `storage[]`。

[▶ 打开此功能：② 输入参数](/?view=chat&step=params)

## 字段 `storage[i]`

| 字段 | 含义 | 单位 | 默认 | 合理范围（参数表） | 硬约束 / 不合理时 |
|---|---|---|---|---|---|
| `name` | 名称 | — | `ESS_1` | 不重复 | 重复：拒绝（项目） |
| `bus` | 接入母线 | — | 4 | [0, 999] | 越界：拒绝 |
| `energy_mwh` | 可用能量容量 | MWh | 50 | [0, 1e5] | ≤ 0：拒绝 |
| `power_mw` | 最大充 / 放电功率 | MW | 12.5 | [0, 1e5] | ≤ 0：拒绝 |
| `eta_ch` | 充电效率 | — | 0.95 | [0.5, 1] | 不在 (0, 1]：拒绝 |
| `eta_dis` | 放电效率 | — | 0.95 | [0.5, 1] | 不在 (0, 1]：拒绝 |
| `soc0` | 日初荷电状态（日末不低于此值） | p.u. | 0.5 | [0, 1] | 须 `0 ≤ soc_min ≤ soc0 ≤ soc_max ≤ 1`，否则拒绝 |
| `soc_min` | SOC 下限（硬底线） | p.u. | 0.1 | [0, 1] | 同上 |
| `soc_max` | SOC 上限 | p.u. | 0.95 | [0, 1] | 同上 |
| `kind` | `ess` 站用储能 / `ups` 可调度 UPS（EUPS） | — | `ess` | 二选一 | 拒绝 |
| `reserve_frac` | UPS 经济调度保留备用比例：运行下限 = soc_min + reserve_frac × (soc_max − soc_min)；应急时退回 soc_min | — | 0 | [0, 1] | 不在 [0, 1]：拒绝 |
| `source_note` | 参数来源 / 【假设】说明 | — | 空 | — | — |

**时长检查**：能量 / 功率（小时）不在 0.25 ~ 12 h 时给出**警告**，仍可运行。

> 本页「拒绝」中关于效率、SOC 顺序以外的正值 / 区间检查，由项目草稿与版本化任务的严格校验执行；SOC 顺序（`soc_min ≤ soc0 ≤ soc_max`）和容量 / 功率 ≤ 0 在会话路径同样拒绝。

## 模型说明

- SOC 递推：e(t+1) = e(t) + Δt × (η_ch × P_ch − P_dis / η_dis)；日末 SOC ≥ 初值（固定启用）。
- 储能循环费为合成常量 5 元/MWh 充放电量，**当前不可配置**（【已知缺陷】T02）。
- 配置构建器中的电池使用单一效率 `eta`（[0.5, 1]）与 SOC 上下限（0 ≤ 下限 < 上限 ≤ 1）。
- 资源库设备模型 `storage` 允许参数：`energy_mwh`、`power_mw`、`eta_ch`、`eta_dis`、`soc0`、`soc_min`、`soc_max`、`reserve_frac`。
