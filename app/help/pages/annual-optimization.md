# 年度 8760 寻优与多目标（工作台原入口）

> **目的**：需求驱动寻优：在全年 8760 h（或代表日 + 8760 复核）上联合优化风 / 光 / 电池 / 蓄冷 / 蓄热 / 热泵 / 冷机 / 散热方式容量与运行，给出成本—碳 Pareto 前沿与折中方案。
> **前置条件**：仿真工作台会话。
> **界面入口**：② 仿真优化 → 🧭 仿真工作台，对话描述目标。状态：【部分实现】（未纳入统一冻结任务；仅 1h）。

[▶ 打开此功能：仿真工作台](/?view=chat)

## 操作

1. 在对话中描述目标与约束，例如「中卫项目寻优：我想看经济性最优和碳排放最优的方案，以及中间的折中」或「绿电不低于 90%、回收期不超过 8 年」。
2. 系统生成可编辑的**目标规格卡**：可「+ 约束」、修改后「按此规格重新寻优」。
3. 输出 Pareto 前沿（ε-约束）、单目标、加权和、字典序方案、对偶解释、边际减排成本、回收期 / NPV；可点「再降10%碳要多花多少钱？」继续追问。

## 限制

- 年度模型为「铜板 + 准稳态冷却」（无 RC 热惯性、无潮流、无 N-1），由「年—日闭环」抽选典型 / 极端日用完整日内引擎复核。
- 投资单价、渗透率等为【假设】量级。
- 只支持 1h；不产生项目冻结任务。
- 【已知缺陷】固定容量全年复核未重新附加原规格全部硬约束（A08）、代表日容量映射命名歧义（A08b）、年度平衡与进口上限口径（A11）尚未修复 / 验证。
- 版本化任务中的纯碳目标被拒绝，纯碳 / Pareto 请走这里。
