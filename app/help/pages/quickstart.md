# 五分钟上手

> **目的**：用最短路径完成一次「可追溯」的仿真：建项目 → 用模板新建场景 → 绑定通用数据 → 发布版本 → 创建并运行冻结任务；另附更轻量的对话工作台路径。
> **前置条件**：服务已启动（Mock 模式即可，无需 API Key）。
> **界面入口**：左侧「① 资源与建模 → 📁 项目与场景」。

[▶ 打开此功能：项目与场景](/?view=foundation)

## 路径 A：项目化闭环（推荐，结果可追溯、可重跑）

### 第 1 步：创建项目

1. 左侧点「📁 项目与场景」。
2. 在「1 · 项目与资料」卡片输入项目名称（例如「中卫园区测试」），点 **创建项目**。
3. 顶部「当前项目模型」条会显示刚建的项目。

### 第 2 步：从模板新建场景

1. 在「2 · 创建独立场景」卡片填写场景名称（例如「方案A·夏季」）。
2. 在模板下拉中选一个模板，例如「风光储直供参考·中卫」或「基础单园区」。
3. 展开「新建场景时间轴」，按需修改时间轴 JSON（地点、年份、时区、起始、步长、长度，见 [时间轴参数](/help/params-axis-library)）。默认 24 点 / 60 分钟。
4. 点 **从模板新建**。场景是模板的独立副本，之后修改不影响模板。

![项目与场景页：创建项目并从模板新建场景](/help/img/f1106-project.png)
*截图：2026-11-06 产品基础层验收（Mock）。图中尚无后来新增的「新建年度CFE / 电网反馈 / GPU 独立场景」控件。*

### 第 3 步：绑定通用数据（可选但推荐）

1. 在「4 · 绑定通用数据与设备版本」卡片，第一个下拉选资源版本（如「公开气象·中卫·2024-07-01」），第二个下拉选绑定目标（气象/电价/碳选「场景公共信号」；负荷选具体数据中心）。
2. 点 **新增绑定并校验**。
3. 如果提示时间轴不一致（`axis_mismatch`），按提示逐字段核对；确认要以数据为准时勾选「同时按所选数据设置草稿时间轴」后再绑定。详见 [数据绑定与时间轴对齐](/help/binding)。

### 第 4 步：校验并发布版本

1. 在「3 · 场景草稿与模型编辑」卡片点 **校验与展开**，查看错误与告警。
2. 没有错误后点 **发布不可变版本**。「5 · 发布历史」表中出现 v1。

### 第 5 步：创建并运行冻结任务

1. 点「下一步：版本化仿真任务 →」或左侧「▶ 版本化仿真任务」。
2. 确认顶部「任务输入版本」选中了刚发布的 v1。
3. 选择目标（先用「运行成本最优」），求解器软限时保持 120 秒，交流校核保持勾选。
4. 点 **创建冻结任务** → 在列表中选中该任务 → 点 **运行所选任务**。
5. 完成后点 **查看当时模型与结果**，进入结果页查看 KPI、热安全、归因等。

[▶ 打开此功能：版本化仿真任务](/?view=tasks)

## 路径 B：对话工作台（最快看到结果，适合探索）

1. 左侧点「🧭 仿真工作台」，点欢迎页任一示例卡片，例如「三数据中心 + 储能调度」。
2. 智能体构建模型后会**暂停在 ② 输入参数**，右侧列出每个参数的值、单位、合理范围和来源标签。
3. 核对后点 **✅ 确认并继续运行**。
4. 在 ⑤ 查看运行日志与交流校核，在 ⑥ 查看结果；可继续追问「为什么」「如果储能翻倍会怎样」。

[▶ 打开此功能：仿真工作台](/?view=chat)

> 路径 B 的结果属于当前会话，不会自动成为项目版本。要纳入项目管理，请在项目页使用「将当前旧会话导入为场景」或「当前会话模型 → 写回场景草稿」。
