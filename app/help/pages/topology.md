## 编辑流程

1. 内置 IEEE14 网络需先点 **🔧 转换为可编辑网络**。
2. 勾选「编辑模式」，点选元件 → 在表单中修改 → **保存修改**；或「添加元件…」新增（母线、线路、变压器、外网、机组、负荷、风光、储能、数据中心、DC 互联、热管理、区域供热网）。
3. 点 **✔ 校验**，查看错误与告警。
4. 点 **▶ 重新仿真**（可勾选交流校核），查看「编辑前 → 编辑后」指标对比。
5. **↶ 撤销 / ↷ 重做**、**↺ 重置布局**、**💾 保存 JSON / 📂 加载 JSON**。

## 拓扑怎样保持有效：错误与告警

| 情况 | 级别 | 系统处理 |
|---|---|---|
| 母线 / 端点编号越界、线路两端同一母线、元件引用不存在 | 错误 | 禁止仿真 |
| 线路两端电压等级不同 | 错误 | 提示用变压器连接 |
| 线路额定 / 长度 / 电抗 ≤ 0；变压器容量 / 短路电压 ≤ 0 | 错误 | 禁止仿真 |
| 电气岛有负荷但没有任何电源 | 错误 | 禁止仿真 |
| 数据中心 IT 容量 ≤ 0；储能功率 / 容量 ≤ 0；风光装机为负 | 错误 | 禁止仿真 |
| 悬空母线（无线路 / 变压器连接） | 告警 | 可继续，其上元件形成孤岛 |
| 变压器高压侧电压低于低压侧 | 告警 | 提示检查是否接反 |
| 纯风光储孤岛；必需负荷峰值下界 > 可靠出力 | 告警 | 提示低风光时段可能无解 |
| PUE 不在 1.0 ~ 3.0；储能时长不在 0.25 ~ 12 h | 告警 | 可继续 |
| 新能源装机远大于线路额定（> 3 倍） | 告警 | 提示可能大量弃电 |

在**项目签出的会话**中，非法的参数 / 拓扑修改会被**回滚**；旧式会话保留原有编辑行为，但发布前仍需严格校验。

## 容量预检

预检区分「装机设计上限」与「固定 / 同时峰值」「必需批任务能量下界」；只有真实欠供（例如固定负荷 3 MW、可用电源 2 MW）才保留告警并导致求解失败。

## 求解后能看到什么

拓扑图（潮流箭头 / 负载率着色）、装机汇总表、日能量桑基图（电 → IT → 热 → 冷却 → 余热 → 供热）、元件详情曲线；可导出 PNG / 交互 HTML / JSON。15 分钟结果的时间滑块为 0–95（末端 23:45）。能流按直流潮流重建，精确电压须看交流校核。

> 任何修改都会让旧结果失效，拓扑图不再显示旧解能流，直到重新求解。
