# 电网再出清与边际碳反馈（opt_grid_feedback）

> **目的**：研究「数据中心按电网信号迁移工作」对系统运行排放与成本的真实影响：基态出清 → 计算信号 → 调度工作 → 真实再出清 → 更新信号。
> **前置条件**：项目已创建；输入为 UTC 整点、1h、1–168 小时。
> **界面入口**：① 项目与场景 → 卡片 2「新建电网反馈独立场景」。状态：【部分实现】（真实 RTS 数据仅闰日 4 小时变体，不是论文全年结果）。

[▶ 打开此功能：项目与场景](/?view=foundation)

> 本模式当前没有真实截图，以下为文字步骤。

## 操作步骤

1. 选择电网反馈预置 → **新建电网反馈独立场景**。
2. 在「独立电网反馈实验」控件中设置：展示信号、最多迭代、FD 步长 MW、LMCE 方法、不稳定策略、「任一信号非固定点则任务failed」→ **写入反馈配置到编辑器**。
3. 保存 → 校验 → 发布 → 版本化任务（cost 封套、关闭交流校核）→ 运行。
4. 结果区查看四种信号策略的预测 Δ 与实际 Δ（运行碳、生命周期附加、USD）、迭代过程、固定点状态；下载独立 ZIP。

## 四种信号

| 信号 | 含义 |
|---|---|
| `lmce` | 节点边际碳排放（系统运行排放对节点负荷的边际），可为负 |
| `lmp` | 节点边际价格 |
| `average` | 区域平均碳强度（零出力时无定义，而不是 0） |
| `excess` | 超额清洁容量（单位 MW，不是吨碳） |

## 要点

- 预测 Δ 与实际 Δ 分列，正值为增排；线性预测可能失效，系统会保留反例。
- 固定点 ≠ 全局最优；不按实际减排择优过滤结果；非收敛和增排结果都会保留。
- 「必须收敛」开启且未收敛时任务 failed，保留 `partial_NOT_ACCEPTED.json`，无 `results.json`。
- 显式拒绝：15min、完整 8784 小时年度、与年度 CFE 联合、三级滚动、日资源绑定 / 日拓扑 / 交流校核、超过 168 小时（不截断）。

参数详解见 [电网反馈与 GPU 参数](/help/params-grid-gpu)。
