# 场景表单 (JSON)（高级）

> **目的**：对**会话**场景做完整参数编辑，适合熟悉字段的高级用户。
> **前置条件**：了解场景字段（见 [参数配置手册](/help/params-overview)）。
> **界面入口**：① 资源与建模 → 高级 → 🧩 场景表单 (JSON)。状态：【已实现】。

[▶ 打开此功能：场景表单](/?view=scenario)

## 用法

1. 在表单中逐项修改，或在「高级：完整 JSON」中直接编辑后点 **从 JSON 更新表单**。
2. 可用「— 场景预设 —」下拉 + **加载预设** 载入案例；**恢复默认** 回到内置合成默认场景。
3. **🗺 预览模型拓扑** 在拓扑页预览。
4. 回到仿真工作台，勾选对话框下方「使用"场景表单"中的场景」再发送请求。

## 注意

- 这是**会话路径**，不直接修改项目草稿。项目化管理请在项目页使用「完整草稿JSON（高级）」或签出编辑。
- 默认数据均为**合成示例数据**。
- 字段由 Pydantic `Scenario` 严格定义；项目草稿中未知字段会被拒绝（例如把 `pue` 拼错）。
- 更推荐在工作台「② 输入参数」中逐项查看与修改，那里会显示单位、合理范围与来源。
