# 仿真工作台：对话 + 六步透明工作流

> **目的**：用中文描述需求，智能体建模、暂停让你核对参数，再求解并解释结论；每一步的参数来源、数学模型、运行日志都可查看。
> **前置条件**：Mock 模式即可（关键词路由，适合演示）；复杂需求请在 [设置](/help/simulators-settings) 中配置真实 LLM。
> **界面入口**：② 仿真优化 → 🧭 仿真工作台。状态：【已实现】。

[▶ 打开此功能：仿真工作台](/?view=chat)

## 六步工作流（右侧面板）

| 步骤 | 做什么 | 你需要关注 |
|---|---|---|
| ① 场景与目标 | 选案例预设与目标（纯成本 / 成本 + 碳），或直接对话描述 | 「载入场景 → 核对参数」 |
| ② 输入参数 | 按分组列出名称、含义、值、单位、合理范围、来源标签 | 越界标红；可直接修改；**确认前不会求解** |
| ③ 模型构建 | 母线 / 线路 / 电源 / 储能 / 数据中心等结构 | 「✏️ 在拓扑编辑器中修改」 |
| ④ 求解配置 | KaTeX 展示本次实际使用的目标项与约束、启用原因、线性化与近似清单 | 求解器、时间上限、基线、交流校核、收益归因 |
| ⑤ 运行与校核 | 进度、运行日志（做了什么 / 为什么 / 输入输出 / 用时）、求解器状态与 Gap、交流校核 | 失败原因 |
| ⑥ 结果与分析 | KPI、基线对比、归因、逐时曲线、假设与局限 | 见 [结果复盘](/help/results-export) |

另有「🔬 研究模式」面板，见 [研究模式](/help/research-mode)。

## 对话路径

1. 点欢迎页示例卡片，或在输入框描述需求（Enter 发送，Shift+Enter 换行）。
2. 输入框上方三个开关：
   - **使用"场景表单"中的场景**：用 [场景表单](/help/scenario-json) 中编辑的场景。
   - **🔬 研究模式**：适合「值不值 / 最优方案 / 为什么」类问题。
   - **自动运行**：默认关闭（推荐），求解前暂停等你确认；打开则直接跑。
3. 智能体构建后暂停在 ②，核对后点 **✅ 确认并继续运行**。
4. 结果出来后「下一步可以…」会给出追问建议：为什么、如果…会怎样、导出可复现报告。

## 参数来源标签

| 标签 | 含义 |
|---|---|
| 用户指定 | 你在界面或对话中明确给出 |
| 智能体推断 | 由对话文本解析或智能体给出的 JSON |
| 默认值 | 引擎内置合成默认值（SYNTHETIC） |
| 案例假设 | 来自案例预设的假设 |
| 公开资料 | 带链接的公开来源 |
| （绑定资源） | 来自项目绑定的资源库版本时，标签按资源来源显示为「案例假设 / 公开资料 / 用户指定」，说明中写明「固定资源 名称 r版本 (ID)；来源；工况」 |

## 注意

- 工具出错时会把错误回灌给智能体修正参数重试（每工具最多 3 次）。
- 会话中的结果属于当前会话；任何参数 / 拓扑修改都会让旧结果失效。
- 年度 CFE、电网反馈、GPU 三种独立模式**没有对话工具**，只能在项目页使用。
