# 常见问题与报错

> **目的**：快速定位常见报错的原因与处理方法。
> **前置条件**：无。
> **界面入口**：报错通常出现在页面顶部消息条、卡片下方状态行或对话中。

## 时间轴与绑定

| 报错 / 现象 | 原因 | 处理 |
|---|---|---|
| `axis_mismatch`，逐字段列出差异 | 资源与草稿的地点 / 年份 / 时区 / 起点 / 步长 / 长度不一致 | 选对应地点的数据；或勾选「同时按所选数据设置草稿时间轴」；跨区请另建场景 |
| 同类/同目标已有绑定；请显式选择"替换同类绑定" | 已有同类绑定 | 用 **替换同类绑定并校验** |
| 没有同类/同目标绑定；请使用"新增绑定" | 想替换但没有旧绑定 | 用 **新增绑定并校验** |
| 当前气象/电价/碳为场景公共信号，不支持设备级target | 选了设备作为气象 / 电价 / 碳目标 | 目标选「场景公共信号」 |
| 负荷绑定需要有效数据中心 target | 负荷未选数据中心 | 选目标数据中心 |
| 日调度支持24点/60分钟或96点/15分钟 | 步长 / 点数不在允许组合 | 改为 60/24 或 15/96 |
| 日调度起始时间必须当地零点 / start 必须带时区偏移 | `start` 格式不对 | 用 `YYYY-MM-DDT00:00:00+08:00` 形式 |
| 单位必须 … | 资源单位不符 | 气象 `degC`、电价 `CNY/kWh`、碳 `tCO2/MWh`、负荷 `MW` |

## 草稿与发布

| 报错 | 原因 | 处理 |
|---|---|---|
| 草稿已被其他操作修改 / 草稿版本冲突 | revision 已变化 | 刷新后重做 |
| 存在待确认项，先确认再发布 | 草稿 `pending` 非空 | 处理待确认项 |
| 模型dt/长度与场景时间轴不匹配 | `dt_hours` 与时间轴不一致 | 用「显式展开为15分钟草稿」或同步修改 |
| 修改后校验失败：… | 参数表修改违反硬约束 | 按提示改回合理值 |
| 场景至少需要一个数据中心 | 删除了全部数据中心 | 添加数据中心 |

## 任务与求解

| 报错 / 现象 | 原因 | 处理 |
|---|---|---|
| 本任务日调度不支持纯碳目标 | 选了纯碳 | 用 `weighted_carbon` 并明确权重；纯碳 / Pareto 用工作台寻优 |
| welfare 必须使用显式任务需求报价 / 每个任务必须提供 value_cny_mwh | 福利目标缺报价 | 在 `jobs` 中补 `value_cny_mwh`，碳权重设 0 |
| 求解时间须在0~600秒 | 软限时越界 | 改为 1–600 |
| 年度CFE仅支持显式cost采购目标且必须关闭日模型AC校核 | 独立模式选了其他目标或开了 AC | 选 cost、关闭交流校核 |
| paper_abstract 必须显式关闭交流校核 | 抽象网络域开了 AC | 关闭交流校核 |
| 任务已执行/正在执行 | 任务只能运行一次 | 「按原快照创建重跑」 |
| 任务 failed（不可行 / 超时） | 模型约束无法同时满足或时间不够 | 查看错误详情；检查可靠电源、热约束、任务窗口；适当放宽或延长软限时 |
| 服务重启后任务 failed | 中断任务不自动续算 | 按原快照重跑 |

## 15 分钟与整数任务

| 报错 | 处理 |
|---|---|
| 〈路径〉 尚不支持15min/整数连续任务；不能默默当作1h能量任务 | 年度 / 三级运行等路径请用 1h、能量型任务场景 |
| VCC尚不支持15min/整数连续任务 | 关闭 VCC（`vcc_mode = off`） |
| 市场沙盘仅支持1h | 交易沙盘使用 1h 资源 |
| 时刻 Xh 必须对齐 dt | 15 分钟下时刻须为 0.25 的倍数 |
| 能量流任务不能携带整数任务状态/required | 设 `execution_mode = "continuous"` 或去掉相关字段 |

## 其他

- **Mock 模式回答很简单 / 没理解我的问题**：Mock 为关键词路由，请参考 [示例提示词](/help/workflows-prompts)，或在设置中配置真实 LLM。
- **「真实提交」返回 403**：设计如此，交易页是沙盘，不能真实下单。
- **MATPOWER / OpenModelica / ParaView 不可用**：当前环境缺少对应命令行工具。
- **图表或页面打不开**：确认服务在运行（`/health` 返回 ok）；本手册不依赖外网。
- **帮助抽屉没有打开**：按 F1 时如浏览器弹出自身帮助，请改用 Shift + /（即「?」键）或右上角「❓ 帮助」。
