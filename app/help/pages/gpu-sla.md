# GPU 离散功率帽与吞吐 SLA（opt_gpu）

> **目的**：在固定 GPU 组（gang）上选择离散功率帽 / 暂停，满足同等工作量、截止期、Flex 窗口吞吐 SLA 与功率预算，最小化全时域电费或做公平对照。
> **前置条件**：每个任务有固定、互不重叠的 GPU 组和校准动作曲线（cap W、实测 W/GPU、相对吞吐）。
> **界面入口**：① 项目与场景 → 卡片 2「新建GPU离散控制独立场景」。状态：【部分实现】（局部产品模式，非论文整篇现场复现）。

## 操作步骤

1. 选择 GPU 预置 → **新建GPU离散控制独立场景**。
2. 在「离散GPU独立模式」控件中设置：
   - **目标/策略**：`energy_cost`（完整时域能量费用）、`fair_minimax`（本产品的吞吐余量 minimax 对照变体，**不是作者 Fair**）、`author_dvfs_headroom_discrete`（按作者公开伪代码的 DVFS 功率 headroom 公平离散实现，非完整 hybrid / resize）。
   - **MIP 相对 gap**：0 ~ 0.01。
   - **留出验证不满足则真实failed**（严格留出验证）。
   - 点 **写入GPU配置到编辑器**；需要 15 分钟时点 **相同阶梯输入明确细化15min**（只把阶梯输入重复 4 次）。
3. 保存 → 校验 → 发布 → 版本化任务（AC 关闭、cost 封套）→ 运行 → GPU 结果区 → 正式 ZIP。

## 规则

- 工作量单位是「该任务参考 gang 等效小时」，不同任务不可互换。
- Flex0 / 1 / 2 / 3 的窗口吞吐下限为 100% / 90% / 75% / 50%；Flex0 额外锁定参考帽。
- 暂停保留进度（忽略 checkpoint 开销），不支持 resize、共享 GPU、跨站迁移。
- 仅 optimal（含请求 gap）才接收结果。
- GPU 结果**不覆盖**整个数据中心的 PUE、冷却或热安全；未知字段（PUE、热网络、日场景储能等）会被拒绝。
- 无独立验证字段时 UI 只显示「规划一致」，不称留出验证通过。

参数详解见 [电网反馈与 GPU 参数](/help/params-grid-gpu)。
