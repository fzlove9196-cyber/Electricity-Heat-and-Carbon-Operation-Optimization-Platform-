# 界面导览

> **目的**：认识六大业务域、顶部上下文条、Ctrl+K 功能搜索、会话列表和模式徽章。
> **前置条件**：无。
> **界面入口**：主界面 `/`。

## 六大业务域（按运营主线 ①→⑥）

| 业务域 | 左侧入口 | 用途 |
|---|---|---|
| ① 资源与建模 | 项目与场景、基础模板库、数据与设备模型库、配置构建器、模型拓扑 / 能流；〔高级〕场景表单 (JSON) | 定义数据中心、电源、储能、散热与拓扑，管理版本 |
| ② 仿真优化 | 版本化仿真任务、仿真工作台、参数透明核对、透明模型 / 数学表述、研究模式 | 求解与透明核对 |
| ③ 三级运行 | 三级优化运行 | 日前基线 → 日内滚动 → 实时跟踪 |
| ④ 电力交易运营 | 运营工作台 (P0) | 沙盘闭环，非真实交易 |
| ⑤ 结果复盘 | 原文案例专页、结果与分析、运行日志与校核 | KPI、基线对比、归因、导出 |
| ⑥ 知识 · 工具 · 设置 | 知识库、技能卡、使用帮助；〔高级与配置〕仿真器 / 工具、设置 | 资料检索、经验复用、配置 |

「高级」分组默认收起，访问其中页面时会自动展开。

## 顶部区域

- **业务域条**：①–⑥ 一键切换业务域。
- **当前项目模型**：项目 / 场景 / 任务输入版本三个下拉，以及「管理模型」。它与对话会话**相互独立**：换场景不会替换对话里的模型。
- **当前位置面包屑**：显示所在域和页面，右侧「下一步：…」按钮引导到主线下一环。
- **二级任务条**：当前域的子页面快捷按钮。
- **❓ 帮助**：打开与当前页面对应的帮助抽屉。

## 功能搜索（Ctrl+K）

按 **Ctrl+K**（Mac 为 ⌘K）聚焦左上角搜索框，输入功能名（如「绑定」「可行域」「审计」「帮助」「参数」），回车跳转到第一项。

## 会话与模式徽章

- 左侧「会话」列表是对话工作台的历史会话，「＋ 新会话」新建。签出草稿、打开历史任务也会生成独立会话副本。
- 左下角徽章显示「🧪 Mock 模式（无需 API Key）」或「🤖 真实 LLM 模式」。

## 快捷键

| 按键 | 作用 |
|---|---|
| Ctrl+K / ⌘K | 聚焦功能搜索 |
| F1 或 Shift + / | 打开当前页面的上下文帮助 |
| Esc | 关闭帮助抽屉 / 快捷提示 / 搜索 |
| Enter / Shift+Enter | 对话框发送 / 换行 |
| Ctrl+/ | 聚焦对话输入框 |

## 深链接

可以直接用地址打开某个页面，例如 `/?view=tasks`、`/?view=foundation`、`/?view=chat&step=params`。当前会话保存在浏览器本地，打开深链接不会丢失。帮助页地址形如 `/help/quickstart`。
