# 配置构建器

> **目的**：不从预设出发，按「数据中心 + 能源 + 散热 + 蓄能 + 余热供热」从零生成一套配置，或一键做方案对比和参数扫描。
> **前置条件**：一个对话会话（新会话，或从项目「签出草稿」得到的编辑会话）。
> **界面入口**：① 资源与建模 → 🧪 配置构建器。状态：【已实现】（散热方式、余热品位等参数多为文献 / 假设值）。

## 操作步骤

1. 展开「散热方式库」查看 6 类散热方式的默认参数与文献来源。
2. 在表单中设置：
   - **数据中心**（可「＋ 数据中心」增加多座）：名称、IT 容量 MW、机柜数、利用率、可调（批处理）比例、散热方式、液冷比例、蓄冷类型 / 容量 / 功率、热泵容量与类型、余热源温度。
   - **电池**：功率 MW、容量 MWh、效率、SOC 上下限。
   - **蓄热**、**虚拟储能开关**（预冷 / 蓄冷 / 余热 / DR）。
   - **电源**：风电、光伏、火电、水电（及日电量）、燃气 CHP、外网购电 / 外送上限、PPA 价格。
   - **供热**：是否启用、末端类型、管线长度、沿程温降、设计热负荷、热价、补热方式等。
3. 点 **校验**：错误阻止构建，告警仅提示。
4. 点 **构建为当前会话场景** → 到 [仿真工作台](/help/workbench) 的 ② 核对参数后求解。
5. 「恢复模板」回到默认配置。

## 一键研究

| 按钮 | 做什么 |
|---|---|
| ❄ 散热方式对比 | 同一配置下比较多种散热方式的能耗、PUE、可行性 |
| 🔋 储能容量扫描 | 扫描电池容量 |
| 🧊 蓄冷容量扫描(夏) | 夏季工况下扫描蓄冷罐容量 |
| ♨ 余热供暖可行性（末端×距离） | 判定可行 / 有条件可行 / 不可行 |
| 运行扫描（自定义） | 1–2 个参数的网格扫描，参数用点路径，例如 `heat.pipe_length_km` 取 `1,5,10`；`dcs.*.cooling_mode` 取 `air_chw,liquid_cold_plate`；`battery.energy_mwh` |

结果输出 KPI 表、柱状图与可行性卡片，并写入会话产物（`cfg_sweep_*`、`cfg_heat_feasibility.*`）。

## 校验规则（会阻止构建的错误）

| 检查 | 规则 |
|---|---|
| 数据中心 | 至少 1 座、名称不重复；IT 容量 > 0；利用率 ∈ (0, 1]；可调比例 ∈ [0, 0.9]；散热方式必须在库中；液冷比例 ∈ [0, 1] |
| 蓄冷 / 热泵 | 容量不能为负；蓄冷容量 > 0 时功率必须 > 0；热泵类型为 standard / high_temp |
| 电池 | 容量 > 0 时功率必须 > 0；0 ≤ SOC 下限 < 上限 ≤ 1；效率 ∈ [0.5, 1] |
| 电源 | 各类容量不能为负 |
| 供热 | 末端类型为 floor / fcu / radiator / primary；管线长度不能为负 |

**告警（不阻止）**：风冷单柜功率密度 > 25 kW 建议液冷；可靠电源（外网 + 火 / 水 / 气 + 储能）小于数据中心峰值估计（IT×1.5）时提示夜间无风可能失负荷 / 不可行。

## 注意

- 构建结果写入**当前会话**。如果这是从项目签出的会话，修改后要回项目页「当前会话模型 → 写回场景草稿」并重新发布，才会进入版本化任务。
- 切换散热方式会按散热方式库重设温度边界、COP 曲线、自然冷却阈值、WUE 与余热源温度。
