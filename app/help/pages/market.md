# 电力交易运营沙盘（P0）

> **目的**：在示范规则下演练聚合资源的日前 — 日内 — 实时 — DR — 结算闭环，用于方法研究与流程演示。
> **前置条件**：无（由案例派生组合）。仅 1h。
> **界面入口**：④ 电力交易运营 → 💹 运营工作台。状态：【部分实现】。

[▶ 打开此功能：运营工作台](/?view=market)

> ⚠ **这不是真实交易。** 「真实提交」按钮固定返回 HTTP 403「真实外部下单不可执行」，并写入拒绝审计。规则包 `demo_ningxia` / `demo_mengxi` / `demo_guangdong` 均为【假设·非官方】示范规则，不代表中国正式交易规则；所有收益为沙盘测算。

## 操作步骤

1. 选择**组合**：中卫（宁夏示范规则）/ 乌兰察布（蒙西示范规则）/ 韶关（广东示范规则）。跨省资源会被剔除并记录原因。
2. 设置 **seed**（随机种子，默认 7）与**操作人**（默认 reviewer2）。
3. 可选：导入价格 CSV（列 `hour,price`）。
4. 点 **▶ 运行 日前→日内→实时→DR→结算 闭环**。
5. 查看净成本 / 对照 / 节省、偏差与考核、DR 申报与响应率、热安全。
6. 在「申报台账与审批」中按 草稿 → 审核 → 沙盘出清 → 结算 推进；审核人必须与编制人不同（四眼原则）；物理检查不通过不可提交。
7. 「审计记录」中的每次操作写入 SHA256 哈希链，可校验完整性。

## DR 基线

- 方法：`similar_days_avg`（默认）/ `prior_n_days` / `adjusted_similar_days`；响应率 ≥ 阈值按补偿价支付，低于下限按考核价罚。
- **DR 基线不能用于正式结算 / 考核**：公开基准的独立留出验证未同时满足误判率要求，只作示范估算。

## 限制

- 对照为「未优化」（批处理均布、储能不动），节省主要来自批处理移峰与储能套利，不是交易策略超额收益。
- 15min 资源显式拒绝。
- 【已知缺陷】重新进入页面可能按案例重建组合、导入价格不持久（A07）；计划量检查不覆盖全部中标段（A06）；批处理需求被截断后仅告警（A09）。
- 申报导出 CSV / XLSX 标注「非真实」，模板为示意，非交易中心正式格式。
