# 欢迎使用在线帮助

> **目的**：了解本手册的结构、怎样最快找到答案。
> **前置条件**：无。本帮助是本地静态网页，不需要 API Key，Mock 模式下也能离线阅读。
> **界面入口**：任意页面右上角「❓ 帮助」；左侧「⑥ 知识 · 工具 · 设置 → 使用帮助」；各模块标题旁的小「?」；快捷键 **F1**（或 **Shift + /**，即「?」）。

本产品是面向数据中心的「算 — 电 — 热 — 碳」耦合仿真与优化平台：用中文对话或表单描述场景，系统透明地展示参数来源、数学模型与求解过程，并把输入、版本、求解器与结果冻结下来，便于复核与重跑。

## 四种找答案的方式

1. **目录**：左侧按产品六大业务域组织，再加「参数配置手册」和「参考」。
2. **全文搜索**：左上角搜索框，支持标题、小节、关键词和参数字段名（例如输入 `pue`、`step_minutes`、`time_limit_s`、`绑定`、`15min`）。多个词用空格分隔表示「同时包含」。
3. **上下文帮助**：在产品任意页面按 **F1** 或点模块标题旁「?」，会直接打开与当前页面对应的篇章。
4. **文章内链接**：「▶ 打开此功能」会回到产品对应页面；在产品内抽屉中打开时，会直接切换视图并关闭抽屉，不会丢失当前会话。

## 本手册中的状态标注

| 标注 | 含义 |
|---|---|
| 【已实现】 | 有可用入口和完整业务规则，并有回归测试；不代表已做最新版浏览器视觉验收 |
| 【部分实现】 | 核心路径可用，但有明确的范围上限（如只支持 1h、只在某个入口可用） |
| 【未实现】 | 产品中没有该能力，或只有占位 |
| 【研究可选】 | 默认关闭、需显式开启的研究性口径，不改变默认行为，也不代表现场可用 |
| 【已知缺陷】 | 已确认但尚未修复的问题 |

## 关于截图

手册中的截图均为本机 Mock 模式下的**真实截图**，每张都注明拍摄日期。2026-11-06 及更早的截图里左侧导航可能是旧版（缺少「项目与场景 / 基础模板库 / 数据与设备模型库 / 版本化仿真任务」等入口），以你当前看到的界面为准。2026-11-07 之后新增的功能（15 分钟时间步、整数连续任务、年度 CFE、电网再出清、GPU 离散控制）**没有当前真实截图**，手册用文字步骤说明，不使用示意图冒充截图。

## 关于数据

产品内置的默认值、示例资源和案例预设均为**合成示例或公开资料整理的等值参考**，只用于方法演示，**不能当作现场实测数据**。可以把本手册（或你自己的资料）上传到知识库供对话检索，但系统不会自动把帮助写入你的知识库。
