# 三级运行：日前 → 日内 → 实时

> **目的**：模拟「日前定基线 → 日内滚动校准 → 实时快速跟踪」，并提供可行响应域、UPS / 柴发与应急兜底。
> **前置条件**：**当前会话**已有日前最优结果（可来自工作台求解，或版本化任务的「查看当时模型与结果」副本）；场景为 **1h、能量型任务**。
> **界面入口**：③ 三级运行 → ⏱ 三级优化运行。状态：【部分实现】。

## 按钮与顺序

| 按钮 | 做什么 |
|---|---|
| 日前基线 | 把当前日前结果保存为版本化基线（功率、IT、冷却 / 蓄冷、DR 承诺、热裕度） |
| 日内滚动 | 从 `from_t`（输入框，默认 8，范围 0–23）起锁定已过时段，按预测补丁重解剩余时段；目标加相对基线偏离罚。可在「SOC实测(JSON，可选)」中填实测 SOC |
| 可行域 | 计算上 / 下调包络，日前 → 日内 → 实时逐级收缩 |
| 实时跟踪 | MPC-lite 或规则跟踪（15 分钟粒度），给出跟踪 RMSE、入口温度、SOC 轨迹 |
| UPS/柴发 | 配置 UPS（`reserve_frac` 备用底线）与柴发（默认 `emergency_only`） |
| 应急 | 一键应急模式：UPS 可用至 `soc_min`，`emergency_only` 柴发放开 |
| 刷新 | 重新读取状态 |

## 规则与限制

- 15min 或连续整数任务场景会报错「三级运行 尚不支持15min/整数连续任务」。
- 实时规则：设施功率高于信号时电池放电、低于时充电（A01 已修复）。
- 柴发启停成本 / 最小运行时长只透明记录，不进目标。
- 实时 MPC 求解异常时有显式 `rules_fallback` 标记。
- 【已知缺陷】按钮中的预测补丁固定为「光伏降10%」，可行域按钮 `from_t` 固定为 8，「UPS/柴发」一键配置以默认假设替换（A10）；设施功率包络只汇总数据中心电网功率（A02）；无储能场景实时跟踪使用默认 40 MWh 虚拟电池（A03）。
- 这是离线仿真，不是实时 EMS，不下发设备指令。
