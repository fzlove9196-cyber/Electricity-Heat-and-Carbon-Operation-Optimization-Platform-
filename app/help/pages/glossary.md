# 术语表

> **目的**：查阅手册与界面中常见术语。
> **前置条件**：无。
> **界面入口**：本页为参考内容。

| 术语 | 说明 |
|---|---|
| 项目 / 场景 / 版本 / 任务 | 产品基础层四级对象；版本不可变，任务冻结输入快照 |
| 草稿 revision | 草稿的乐观锁序号，保存 / 写回 / 发布时需匹配 |
| 绑定（binding） | 把资源库中固定版本的数据或设备模型接入草稿 |
| `axis_mismatch` | 资源与草稿的时间轴字段不一致 |
| 冻结快照 / `input_hash` | 任务创建时的完整输入副本及其摘要 |
| 签出会话 | 从版本或草稿生成的可编辑会话副本 |
| 写回 | 把会话模型保存回场景草稿（会解除旧绑定） |
| PUE | 电能利用效率 = 数据中心总用电 / IT 用电 |
| 动态 PUE | 热耦合模式下由冷却负荷逐时计算的 PUE |
| RC 热模型 | 机房空气快节点 + 建筑 / 机架慢节点的两节点热容—热阻模型 |
| 热安全 | 入口温度、温变率、冷机 N−1 等约束全部满足 |
| TES | 蓄冷（冷冻水 / 冰）储能 |
| DC-OPF | 直流最优潮流（B-θ 线性化） |
| 交流校核 | 用 pandapower 在指定时刻做交流潮流检查 |
| CFE | 无碳电力（carbon-free energy） |
| LMCE | 节点边际碳排放 |
| LMP | 节点边际电价 |
| VCC | 虚拟容量曲线（灵活负荷容量整形） |
| DR | 需求响应 |
| goodput | 任务实际有效完成的工作量 |
| SLA | 服务水平约束，GPU 模式中为吞吐比例下限 |
| gang | 固定分配给一个任务的 GPU 组 |
| Mock 模式 | 无真实大模型时的规则化对话模式 |
| 研究可选 | 默认关闭、需显式开启的研究性能力 |
