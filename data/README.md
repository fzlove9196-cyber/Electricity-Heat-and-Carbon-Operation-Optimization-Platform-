# data/ 目录说明

本目录在运行时由应用创建或更新，**不要把密钥或生产数据提交进 Git**。

## 版本库中保留什么

仓库只保留本说明（以及启动后由程序自动创建的空结构）。`knowledge_seed/`（仓库根目录）是知识库的种子文档来源。

## 被排除、不进入 Git 的内容及原因

| 路径 | 大约体积（导出时） | 原因 |
|---|---|---|
| `foundation.sqlite3` | 229 MB（超过 GitHub 100 MB 限制） | 产品基础层项目/场景/任务业务库，属运行时数据；首次使用相关功能时由程序创建 |
| `sessions/` | 约 31 MB，数千个会话文件 | 运行时聊天与研究会话，属用户/业务数据 |
| `lancedb/` | 约 1.2 MB | 向量索引缓存，可按知识库页「重建向量索引」再生 |
| `knowledge.db` | 约 92 KB | 知识库 SQLite，可由种子与上传文档重建 |
| `settings.json` | 很小，权限 0600 | 可保存 LLM API Key 等配置，已列入 `.gitignore` |
| `market/` | 约 84 KB | 运营沙盘运行状态，属运行时数据 |
| `docs/` | 知识种子的散列副本 | 运行时缓存，源文件在 `knowledge_seed/` |

首次启动后，应用会按需创建这些文件。pytest 通过 `tests/conftest.py` 把 `DATA_DIR` 与 `ARTIFACT_DIR` 指到临时目录，不依赖本目录中的业务库。

如需备份一个正在使用的实例，请在本地单独归档 `data/` 与 `artifacts/`，不要推送到公开仓库。
