# 算-电-热-碳耦合建模方法（数据中心 · 虚拟储冷/储热 · 需求响应 · 热安全）

本文档说明 sim-agent 引擎 `app/tools/thermal.py` + `sdco_engine.py` 中“算-电-热-碳”耦合模型的建模方法、线性化近似、参数取值与参考文献，供智能体检索与用户核对。

## 1. 为什么要耦合
- **算→电**：IT 功率由算力负载（交互式 + 可时移批处理/任务 + 跨中心迁移）决定。
- **电→热**：IT 电功率几乎全部转化为热量（≈100%），必须被冷却系统实时排出。
- **热→电**：冷却电耗 = 冷量 / COP，COP 随室外温度变化（夏季午后最差），自然冷却在低温时段可用 → PUE 是动态的（中卫夏季 1.12–1.34，冬季 1.05–1.10）。
- **热→热**：数据中心余热可经热泵提温后向区域供热网供热（北方冬季），替代燃煤/燃气锅炉。
- **碳**：总碳 = Σ 逐时碳强度 × 用电 − 余热替代锅炉的热碳抵扣；碳价/碳权重进入目标函数。
- **安全**：入口温度、温升速率、冷量冗余（N+1）是硬约束——算力调度、预冷、需求响应都不能越过热安全边界。

## 2. 数据中心集总 RC 热模型（两节点）
- 空气/入口温度节点 T^in（热容 C_a，快）与 建筑/机架热质量节点 T^m（热容 C_m，慢）：
  - C_a (T^in_t − T^in_{t−1}) = P^IT_t (1 + φ/2) − Q^room_t − UA_am (T^in_t − T^m_t) + UA_env (T^out_t − T^in_t)
  - C_m (T^m_t − T^m_{t−1}) = UA_am (T^in_t − T^m_t)
- 隐式欧拉离散（Δt = 1 h），对任意热容都数值稳定，且为线性等式约束。
- Q^room = 冷机冷量 − 蓄冷罐充冷 + 自然冷却 + 蓄冷罐放冷 + 热泵蒸发侧取热。
- 参数量级（假设，按 IT 容量缩放）：C_a ≈ 0.01·IT MWh/K、C_m ≈ 0.08·IT MWh/K、UA_am ≈ 0.05·IT MW/K。
- 参考：Zhang et al. 2014 (IEEE TSG) 数据中心热惯性需求响应；Van Gilder & Zhang 机房集总模型；Lucchese 2019 数据中心热回收与能流。

## 3. 冷却系统与动态 PUE
- 冷机 COP 线性近似：COP_t = clip(COP_ref − k·(T^out_t − 25), COP_min, COP_max)，逐时**预先计算** → 冷机电功率 Q/COP_t 为线性（避免双线性）。
- 冷却塔/水泵：a·Q（kW_e/kW_th）；自然冷却（板换/间接蒸发）：可用冷量 = Q^fc_max · clip((T_zero − T^out)/(T_zero − T_full), 0, 1)，电耗 Q^fc/COP^fc。
- 电网侧功率 P^dc = P^IT(1+φ) + Q^ch(1/COP_t + a) + Q^fc/COP^fc + H^hp/COP^hp。
- 动态 PUE_t = (P^IT + P^cool + P^other)/P^IT（热泵用电单独报告，ERF = 再利用热/总能耗，The Green Grid 定义）。
- 物理合理性：PUE 应落在 1.05–1.5；中国新建大型/超大型数据中心 PUE 要求 ≤1.25（枢纽节点 ≤1.2，《新型数据中心发展三年行动计划》）。

## 4. 虚拟储冷（预冷）与显式蓄冷
- **虚拟储冷**：利用机房空气 + 建筑结构热惯性，在低电价/高 COP 时段把入口温度压到下限附近（预冷），在高电价/DR 时段让温度在推荐~允许区间内回升，减少冷机出力。约束：日末 T^in_23 ≤ T^0、T^m_23 ≤ T^0（不透支热惯性）。
- **蓄冷罐**（冷冻水/冰蓄冷）：S_t = (1−ℓ)S_{t−1} + Q^c_t − Q^d_t，容量/功率上限，日末 S_23 ≥ S_0。
- 参考：Wang et al. 2019 Applied Energy “Data center thermal energy storage for demand response”；ASHRAE Handbook – HVAC Applications Ch.51 Thermal Storage。

## 5. 虚拟储热与余热回收
- 热泵供热 H^hp ≤ 容量，蒸发侧取热 H^hp(1−1/COP^hp) ≤ γ·P^IT（可回收比例，液冷高、风冷低）。
- 供热网单节点热平衡：(1−ℓ_pipe)ΣH^hp + 放热 − 蓄热 = 售热 ≤ 可接纳热负荷；热网管道水体热惯性/蓄热罐视作**虚拟储热**。
- 收益 = 售热价 × 售热量；热碳抵扣 = 锅炉排放因子 × 售热量（燃煤 ≈ 0.40、燃气 ≈ 0.22 tCO2/MWh_th：燃料排放因子 ÷ 锅炉效率）。
- 案例：中卫、和林格尔、张家口等北方枢纽冬季供暖季长（5–6 个月），数据中心余热供暖已有示范（如张北阿里、腾讯天津数据中心余热供暖项目报道）。

## 6. 热安全边界（硬约束）
- ASHRAE TC9.9 Thermal Guidelines（2021, 第 5 版）：A1 级推荐 18–27°C，允许 15–32°C；温度变化率 ≤ 5°C/h（含磁带设备）或 20°C/h。
- 模型硬约束：T_min ≤ T^in ≤ T_allow；|ΔT^in| ≤ ramp；冷机出力 ≤ 装机×(n−1)/n（N+1）；末端排热 ≤ CRAH 能力；IT ≤ 可用冷却能力（稳态充足性）。超过推荐上限部分按 元/(K·h) 软惩罚，体现“风险-收益”权衡。
- 输出：最小/最大入口温度、距允许上限裕度、超推荐小时数、各约束起作用（binding）小时数、违规列表。

## 7. 电网需求响应（DR）
- 事件：时段 [s, e)，削峰（reduce）或填谷（increase），要求量 R^req（MW），补偿价 π^dr（元/MWh），未达考核 ρ。
- 基线方法：plan（无 DR 的日前优化计划，最严格，避免“本来就会做”的虚假响应）、bau（无协同基线）、given（电网下发基线，如前 5 个相似日均值）。
- 约束：R_t ≤ 基线 − 实际（削峰）、R_t ≤ min(R^req, 申报能力)，可选强制 R_t ≥ R^req；目标 −π^dr ΣR + ρ Σ缺额。
- 数据中心可用资源：批处理时移、跨中心迁移、预冷（虚拟储冷）、蓄冷罐、电储能、余热热泵启停。
- 政策参考：国家发改委《电力需求侧管理办法（2023 年版）》；宁夏/内蒙古需求响应实施方案（削峰补偿上限 2–4 元/kWh 量级，各年不同，需按当年文件核对）。

## 8. 碳耦合
- 逐时平均因子（MEE 区域/省级因子 × 日内形状）或边际因子（边际机组，通常为燃煤 0.85–0.95 tCO2/MWh）；`carbon_basis` 切换。
- 目标 = 成本 + w·λ·(Σ CI_t P^dc_t − EF_boiler Σ H^del_t)。

## 9. 线性化与近似清单
1. 两节点集总 RC，入口温度为机房平均值，不刻画热点/气流组织（需 CFD 复核）；
2. COP 仅与室外干球温度线性相关，忽略部分负荷率与冷冻水温重设；
3. 自然冷却按温度线性插值；冷却塔/水泵按冷量比例；
4. 热泵 COP 常数；热网单节点、无输送时延与水力约束；
5. 1 h 步长，日前确定性；DR 基线 plan 法需先求一次无 DR 解；
6. 全模型为 LP（HiGHS），无整数变量；N+1 以冷量折减表示，不建模冷机启停。
