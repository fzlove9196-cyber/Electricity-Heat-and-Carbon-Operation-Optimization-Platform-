## 接入建议
1. Alibaba GPU trace → 按小时聚合 GPU 数 × 单卡功率 → 训练负载曲线；Azure LLM trace → 每小时 token 数 × 每 token 能耗 → 推理曲线。
2. Google 2019 → 区分 production/best-effort 优先级，作为交互/批处理比例依据。
3. 碳强度：无实时接口时，用生态环境部区域/全国因子 × 日内光伏形状构造合成逐时曲线，并标注为合成。
