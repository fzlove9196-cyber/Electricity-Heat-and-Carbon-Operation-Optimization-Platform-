# 算电协同建模方法笔记（含公式）

符号：t 时段，b 母线，i/k 数据中心，j 批任务，g 机组。P^IT 为 IT 功率，P^DC 为数据中心总功率。

## 1. 数据中心功率模型
- 常数 PUE：P^DC_i,t = PUE_i · P^IT_i,t
- 服务器线性功率：P^IT = N_on·(P_idle + (P_peak − P_idle)·u)，u 为利用率。
- 温度相关冷却（保持 LP 可用分段线性）：P^DC = P^IT·(1 + a + b·max(0, T_out,t − T_free))；冷水机 COP 随冷凝/蒸发温差增大而下降，湿球温度低于阈值可自然冷却。参考：https://actes.sge-conf.fr/2016/articles/article_86849.pdf ，https://research.google.com/pubs/archive/42542.pdf
- 无功：Q = P·tanφ（本应用 pf_q_ratio）。

## 2. 负载分类
- 交互式/在线（时延敏感）：仅可空间迁移，受时延 SLA 约束。
- 批处理/训练（延迟容忍）：可时间平移，有释放时刻 r_j、截止期 d_j。
- AI 训练：可暂停/降频（Emerald AI 示范 25%）；推理：可调 batch size。

## 3. 时间平移（任务级）
Σ_{t=r_j}^{d_j} p_j,t = E_j ；0 ≤ p_j,t ≤ P^max_j ；t ∉ [r_j,d_j] ⇒ p_j,t = 0
日内总量形式（本应用当前实现）：Σ_t p^batch_i,t = E^batch_i。
Google VCC：对灵活负载设置逐时容量上限 VCC_t，且 Σ_t VCC_t ≥ 日需求（高概率完成）。

## 4. 空间迁移
交互负载守恒：Σ_i λ_i,t = Λ_t ；迁移量 m_ik,t ≥ 0，Σ_k m_ik,t ≤ M_max
时延约束：lat_ik > L_max ⇒ m_ik,t = 0；带宽：m_ik,t·δ ≤ BW_ik
迁移能耗：额外功率 κ·Σ m_ik,t。M/M/1 时延：D = 1/(μ·n − λ) ≤ D_max ⇒ n ≥ (λ + 1/D_max)/μ（线性化服务器数约束，Liu 2011）。

## 5. 电网侧（DC-OPF，本应用已实现）
Σ_g P_g,b,t − P^load_b,t − Σ_i∈b P^DC_i,t = Σ_l flow_l,t（出 − 入）；flow_l = (θ_f − θ_t)/x_l；|flow_l| ≤ F_l
节点边际电价 LMP_b,t = 功率平衡约束对偶变量，可回传给 DC 形成价格响应。

## 6. 碳感知目标
min Σ c_g·P_g,t + λ_c·Σ ci_b,t·P^DC_b,t ；或以发电侧计：碳 = Σ e_g·P_g,t。
边际碳强度 vs 平均碳强度：引导平移时宜用边际值；核算用平均值（全国 2023 年 0.5306 kgCO₂/kWh）。
绿电占比 = 光伏/风电供给 DC 电量 / DC 总电量。

## 7. 储能 / UPS
SOC_t = SOC_{t-1} + η_c·P^ch_t − P^dis_t/η_d ；SOC_min ≤ SOC ≤ SOC_max
提供调频备用 r_t：P^dis_t + r_t ≤ P^max ，SOC_t − r_t·Δ ≥ SOC_reserve（保留 UPS 后备时间）。

## 8. 爬坡与波动
|P^DC_t − P^DC_{t-1}| ≤ R（AESO 讨论的 TCDC 爬坡量级 ±10 MW/min）。
AI 训练功率可建模为方波/周期随机过程 P(t) = P̄ + A·sq(2πf t)+ε，送入 ANDES 时域仿真观察振荡（arXiv 2508.16457）。

## 9. 不确定性方法
- 两阶段随机规划：min c^T x + Σ_s π_s·Q(x, ξ_s)
- 机会约束：Pr(P^PV_t ≥ 需求缺口) ≥ 1 − ε，高斯近似 ⇒ μ − z_{1−ε}σ 的确定性等价
- 鲁棒：预算不确定集 |ξ − ξ̂| ≤ Γ·Δ，列与约束生成（C&CG）
- Wasserstein DRO：Appl. Energy 2025；TPWRS 2025 概率性能保证
