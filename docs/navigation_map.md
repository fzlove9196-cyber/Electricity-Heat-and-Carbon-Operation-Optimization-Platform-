# 导航地图（信息架构 v2，2026-11-06）

原则：只重组入口、不重做功能；对话驱动仍是默认首屏；所有旧 `data-view`、`#v-*` 视图 ID、`show()`、`WF.go()` 保持兼容。

## 三层结构
- **一级（顶部业务域条 `#domBar`）**：按运营任务主线 ①→⑥ 排序，高亮当前域。
- **二级（左侧 `#iaNav` 分组 + 页内任务条 `#subBar`）**：当前域的任务；"高级/配置"项收在 `<details>` 内，访问时自动展开。
- **定位与引导（`#crumb`）**：显示“当前位置 域 › 任务 › 工作流步骤”，并给出一个“下一步”按钮串起主线。
- **搜索（左上 `#navSearch`，Ctrl+K）**：按名称/描述/域检索全部入口（含申报台账、审计、DR、UPS/柴发、可行域等页内功能）。
